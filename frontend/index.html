Run — Classification

Purpose: Start an asynchronous classification job. Upload a FASTA file and choose a model to run; the server will queue the job and return immediately with a job id and output path. Some parameters are enforced by the server.

Inputs

  • FASTA (file) — required. FASTA file with sequence headers expected by the selected model.
  • model — choose one of classifyte, terl, or yoro.
  • modelFile — optional selection of the model to use (lists available models for the selected model type).
  • ClassifyTE-specific options: algorithm (LCPNB or NLLCPN) and
  • YORO-specific options: window, threads, threshold, cycles, and autoLabel.

Server behavior

  • The API queues jobs and returns immediately with a job id and output path.
  • The server will auto-generate the output directory when you omit it.
  • Server-enforced flags: clean=true, verbose=true, and autoLabel=true for /run. You can still pass these fields but the server may override them.

    Evaluate — Generate Metrics
    
                
    Purpose: Compute standardized evaluation metrics from a predictions
                    CSV (must contain ground-truth labels when required). The job runs asynchronously and returns a job
                    id immediately.
    

                
    
                    
    Inputs
    
                    
      
                        
    • predictionsFile (CSV) — required. The CSV should contain at minimum the
                            columns used by the evaluator (e.g. Actual_Label,
                            Predicted label).
                        
      • 
                        
    • format — choose detailed, summary or
                            json depending on the output you need.
                        
      • 
                    
    

                    
    Server behavior
    
                    
      
                        
    • The server sets verbose=true and will create an output directory automatically
                            when omitted.
      • 
                        
    • The evaluator generates JSON and text reports; include Actual_Label in the predictions CSV
                            to produce full metrics.
      •

    Quick reference — endpoints
    

            
    
                
    /run — classification
    
                
    Purpose: Classify transposable elements in DNA sequences using machine learning models. Upload a FASTA file containing DNA sequences and select a classification model (ClassifyTE, TERL, or YORO). The system automatically labels sequences, runs the selected model, and optionally evaluates the results against known annotations.
    
            
    

            
    
                
    /map-labels — FASTA header mapping
    
                
    Purpose: Standardize and validate FASTA sequence headers according to a hierarchical taxonomy. This command maps custom or inconsistent sequence labels to a unified classification tree, ensuring compatibility across different tools and datasets. Useful for preparing datasets or validating existing annotations.
    
            
    

            
    
                
    /evaluate — metrics
    
                
    Purpose: Assess classification model performance by computing comprehensive metrics (precision, recall, F1-score, confusion matrices). Compare predicted labels against ground-truth annotations to quantify model accuracy at multiple taxonomic levels. Produces both human-readable reports and machine-readable JSON output.
