# TE Eval Tool — Metrics Visualization

**Versão:** 5.0.1 | **Data:** Janeiro 2026

## Overview

The **Metrics Visualization** feature provides an interactive, client-side interface for visualizing evaluation reports generated by the TE Eval Tool. This tool allows researchers to upload and analyze their classification metrics through beautiful, responsive charts and detailed breakdowns.

## Features

### 📊 Interactive Charts
- **Overall Performance Metrics**: Bar chart displaying Accuracy, Precision, Recall, F1-Score, and Specificity
- **Advanced Metrics**: Radar chart showing Cohen's Kappa, Matthews Correlation Coefficient, Youden's J Statistic, and F1 consistency
- **Hierarchical Metrics**: Line chart comparing standard vs hierarchical classification metrics
- **Per-Class Performance**: Detailed table and bar chart showing metrics for each classification class

### 🎯 Supported File Formats
- `evaluation_report.txt` — Complete text report with all metrics and details
- `metrics_summary.json` — JSON file with summary metrics

### 🔒 Privacy & Security
- **100% Client-Side Processing**: All file parsing and visualization happens in your browser
- **No Server Upload**: Your data never leaves your computer
- **No Dependencies on Backend**: Works completely offline once the page is loaded

## How to Use

### Step 1: Generate Evaluation Report
1. Go to the main TE Eval Tool interface ([index.html](index.html))
2. Navigate to the **Evaluate** tab
3. Upload your predictions CSV file with ground truth labels
4. Submit the evaluation job
5. Download the generated `evaluation_report.txt` or `metrics_summary.json`

### Step 2: Visualize Metrics
1. Open the **Visualize Metrics** tab in the main interface, or
2. Directly access [metrics_visualization.html](metrics_visualization.html)
3. Upload your evaluation report file using:
   - **Click**: Click the "Choose File" button
   - **Drag & Drop**: Drag your file directly onto the upload area

### Step 3: Explore Your Metrics
Once uploaded, you'll see:
- **Summary Section**: Quick overview with total samples, number of classes, and overall accuracy
- **Main Metrics Cards**: Large, easy-to-read cards for key performance indicators
- **Interactive Charts**: Multiple chart types showing different aspects of your model's performance
- **Per-Class Breakdown**: Detailed table showing precision, recall, F1-score, and support for each class

## Technical Details

### Technologies Used
- **Chart.js 4.4.0**: Modern charting library for interactive visualizations
- **Vanilla JavaScript**: No framework dependencies for fast loading
- **Shared CSS**: Uses the same styling as the main TE Eval Tool interface

### File Parsing

#### Text Report Parsing
The tool can parse `evaluation_report.txt` files and extract:
- Summary metrics (accuracy, F1-score, total samples, number of classes)
- Standard metrics (precision, recall, specificity)
- Advanced metrics (Cohen's Kappa, Matthews Correlation, Youden's J)
- Hierarchical metrics (hierarchical precision, recall, F1-score)
- Per-class metrics (precision, recall, F1-score, support for each class)

#### JSON Parsing
For `metrics_summary.json` files, all metrics are directly loaded from the JSON structure.

### Chart Types

1. **Bar Chart** (Overall Metrics)
   - X-axis: Metric names
   - Y-axis: Values (0-100%)
   - Color-coded bars for each metric

2. **Radar Chart** (Advanced Metrics)
   - Multi-axis visualization showing balance across different robust metrics
   - Normalized scale (0-100%)

3. **Line Chart** (Hierarchical Comparison)
   - Compares standard vs hierarchical metrics
   - Shows improvement from hierarchical classification

4. **Bar Chart** (Per-Class F1-Scores)
   - Individual bars for each classification class
   - Highlights performance variations across classes

## Metrics Explained

### Standard Metrics
- **Accuracy**: Overall correctness of predictions
- **Precision**: Proportion of positive identifications that were actually correct
- **Recall**: Proportion of actual positives that were identified correctly
- **F1-Score**: Harmonic mean of precision and recall
- **Specificity**: True negative rate

### Advanced Metrics
- **Cohen's Kappa**: Measures inter-rater agreement, accounting for chance
- **Matthews Correlation Coefficient (MCC)**: Balanced measure for imbalanced datasets
- **Youden's J Statistic**: Sensitivity + Specificity - 1
- **F1 Consistency**: Standard deviation of F1-scores across classes (inverted for visualization)

### Hierarchical Metrics
- **Hierarchical Precision/Recall/F1**: Metrics computed using taxonomic hierarchy
- **Hierarchical Distance**: Average/max distance in the classification tree between predicted and true labels

## Troubleshooting

### File Upload Issues
- **Problem**: File won't upload
- **Solution**: Ensure the file is a `.txt` or `.json` file and is properly formatted

### Parsing Errors
- **Problem**: "Error parsing file" message appears
- **Solution**: Verify that the file is a valid evaluation report generated by TE Eval Tool

### Missing Metrics
- **Problem**: Some metrics show "N/A"
- **Solution**: This is normal if the evaluation didn't generate all metrics (e.g., hierarchical metrics may not be available for all runs)

### Charts Not Displaying
- **Problem**: Charts don't render
- **Solution**: 
  - Check browser console for errors
  - Ensure JavaScript is enabled
  - Try refreshing the page
  - Check that Chart.js CDN is accessible
